5.1 Maximum Likelihood: Theory

5.1.1 Likelihood, Score, and Hessian

A model specifies the density or probability of the data \(D\) given a parameter \(\theta\), written \(f(D \mid \theta)\). As a function of \(D\) with \(\theta\) fixed it is the sampling distribution; as a function of \(\theta\) with \(D\) observed it is the likelihood. For independent observations \(x_1, \ldots, x_n\), \[L(\theta) = \prod_{i=1}^{n} f(x_i \mid \theta), \qquad \ell(\theta) = \log L(\theta) = \sum_{i=1}^{n} \log f(x_i \mid \theta).\]

We always work with \(\ell\): the product underflows to zero for even moderate \(n\), and sums are easier to differentiate. The maximum likelihood estimator maximizes \(\ell\), and where \(\ell\) is smooth with an interior maximum, \(\hat\theta\) solves the score equation \[S(\theta) = \ell'(\theta) = 0, \qquad \ell''(\hat\theta) < 0 .\]

Three quantities recur throughout the chapter:

  • the score \(S(\theta) = \ell'(\theta)\), which locates the maximum;
  • the observed information \(J(\theta) = -\ell''(\theta)\), the curvature of the log-likelihood at \(\theta\);
  • the expected information \(n I(\theta) = -E_D\left[\ell''(\theta; D)\right]\), its expectation under the model.

The second derivative therefore plays a double role. It determines how a Newton-type algorithm steps toward the maximum, and it determines how precisely the data pin the parameter down. An optimizer that computes the curvature has computed the standard error at the same time.

5.1.2 Closed Form: the Normal Mean

Let \(X_1, \ldots, X_n\) be iid \(N(\mu, \sigma_0^{2})\) with \(\sigma_0^{2}\) known. Using the identity \(\sum_i (x_i - \mu)^2 = \sum_i (x_i - \bar x)^2 + n(\bar x - \mu)^2\), \[\ell(\mu) = -\frac{n}{2}\log\left(2\pi\sigma_0^{2}\right) - \frac{1}{2\sigma_0^{2}}\sum_{i=1}^{n}(x_i - \mu)^{2} = C - \frac{n}{2\sigma_0^{2}}(\mu - \bar x)^{2} .\]

Differentiating, \[S(\mu) = \frac{n}{\sigma_0^{2}}\left(\bar x - \mu\right), \qquad \ell''(\mu) = -\frac{n}{\sigma_0^{2}}, \qquad \hat\mu = \bar x .\]

Every feature of the general theory is visible here in exact form. The log-likelihood is a downward parabola, so it has a unique maximum. The score is linear, so the score equation is solved in one line. The curvature \(J(\mu) = n/\sigma_0^{2}\) does not depend on \(\mu\) or on the data, so observed and expected information coincide, \(J = nI\), and both grow linearly with \(n\): doubling the sample doubles the sharpness of the peak and halves the variance of \(\hat\mu\).

5.1.3 Consistency, Asymptotic Normality, and Fisher Information

Under regularity conditions — the support of \(f\) not depending on \(\theta\), the true value interior to the parameter space, and two derivatives passing under the integral sign — the MLE has three properties as \(n \to \infty\), with \(\theta_*\) the true parameter.

Consistency. \(\hat\theta \to \theta_*\) in probability. The reason is that \(\ell(\theta)/n\) converges to \(E_{\theta_*}[\log f(X \mid \theta)]\), which by the information inequality is maximized at \(\theta = \theta_*\): the log-likelihood surface converges to one whose peak is at the truth.

Asymptotic normality. \[\hat\theta \;\dot\sim\; N\left(\theta_*,\ \left[n I(\theta_*)\right]^{-1}\right), \qquad I(\theta) = -E_X\left[\frac{\partial^{2}}{\partial\theta^{2}}\log f(X \mid \theta)\right] = E_X\left[\left(\frac{\partial}{\partial\theta}\log f(X\mid\theta)\right)^{2}\right].\]

A sketch: expand \(S(\hat\theta) = 0\) about \(\theta_*\) to get \(\hat\theta - \theta_* \approx S(\theta_*)/\{-\ell''(\theta_*)\}\). The numerator is a sum of iid mean-zero terms, hence asymptotically normal with variance \(nI(\theta_*)\); the denominator converges to \(nI(\theta_*)\) by the law of large numbers. Dividing gives variance \([nI(\theta_*)]^{-1}\).

Asymptotic efficiency. No consistent estimator has smaller asymptotic variance — the Cramér–Rao bound is attained.

Since \(\theta_*\) is unknown, the variance is estimated by substituting \(\hat\theta\). Two versions are available: the expected information \(nI(\hat\theta)\), which requires the expectation analytically, and the observed information \(J(\hat\theta) = -\ell''(\hat\theta)\), which requires only the curvature that a Newton step already computes. By the law of large numbers \(J(\hat\theta)/n \approx I(\hat\theta)\), and both give \[\widehat{\mathrm{SE}}(\hat\theta) = J(\hat\theta)^{-1/2} \quad\text{or}\quad \left[nI(\hat\theta)\right]^{-1/2}, \qquad \hat\theta \pm 1.96\,\widehat{\mathrm{SE}}(\hat\theta).\]

These are asymptotic statements. A flat log-likelihood — small curvature — gives a large standard error, and a log-likelihood that is far from quadratic gives a standard error that should not be trusted at all; the last section of this chapter shows a case of exactly that.

5.1.4 Demonstration: the Cauchy Location Model

The Cauchy density \(f(x \mid \theta) = 1/\{\pi[1 + (x - \theta)^2]\}\) has no closed-form MLE: \[\ell(\theta) = -n\log\pi - \sum_{i=1}^{n}\log\left(1 + (x_i - \theta)^{2}\right), \qquad S(\theta) = \sum_{i=1}^{n}\frac{2(x_i - \theta)}{1 + (x_i - \theta)^{2}} .\]

The score equation is a polynomial equation of degree \(2n - 1\). Plotting \(\ell\) for samples of increasing size shows the peak sharpening around the truth, which is consistency and growing information in one picture.

Code

5.2 Univariate Optimization Algorithms

5.2.1 Three Equivalent Formulations

The same task can be posed three ways, and the algorithms below attack different versions of it:

  • maximize \(\ell(\theta)\);
  • minimize \(f(\theta) = -\ell(\theta)\);
  • find a root of \(S(\theta) = \ell'(\theta)\).

Root-finders are usually faster because they use derivative information, but they locate any stationary point, including minima and saddle points. Direct optimizers need only function values and always move toward a maximum, but converge more slowly. Which to prefer depends on whether derivatives are available and whether the function is smooth.

Each method below is illustrated with a schematic showing its first few iterations. To keep the pictures comparable they all use the same small problem: the per-observation log-likelihood of the zero-truncated Poisson model of the next section, with \(\bar x\) fixed at 1.8. The root of its score is marked in every figure.

Code 
xbar_d <- 1.8                                             # fixed sample mean

ll_d <- function(l) xbar_d * log(l) - l - log(1 - exp(-l))          # log-likelihood
S_d  <- function(l) xbar_d / l - 1 / (1 - exp(-l))                  # score
dS_d <- function(l) -xbar_d / l^2 + exp(-l) / (1 - exp(-l))^2       # its derivative
I_d  <- function(l) 1 / (l * (1 - exp(-l))) - exp(-l) / (1 - exp(-l))^2   # information
g_d  <- function(l) xbar_d * (1 - exp(-l))                          # fixed-point map

lstar <- uniroot(S_d, c(0.2, 5))$root
c(root = lstar, contraction_factor = xbar_d * exp(-lstar))

5.2.2 Fixed-Point (Simple) Iteration

Rearrange the score equation algebraically into the form \(\theta = g(\theta)\) and iterate \(\theta_{k+1} = g(\theta_k)\). If \(g\) maps an interval into itself and \(|g'(\theta^{*})| < 1\) at the fixed point, the mean value theorem gives \[\left|\theta_{k+1} - \theta^{*}\right| = \left|g(\theta_k) - g(\theta^{*})\right| \le \left|g'(\xi)\right| \left|\theta_k - \theta^{*}\right| ,\] so the error contracts by roughly the constant factor \(|g'(\theta^{*})|\) at each step. This is linear convergence: a fixed number of digits is gained per iteration, and the closer \(|g'|\) is to 1 the slower the progress.

Code 
fixed_point <- function(g, x0, tol = 1e-10, maxit = 500) {
  for (k in 1:maxit) {
    x1 <- g(x0)
    if (abs(x1 - x0) < tol) return(c(root = x1, iter = k))
    x0 <- x1
  }
  stop("not converged")
}

The mechanism is easiest to see as a cobweb: from \(\lambda_k\) on the diagonal, move vertically to the curve \(g\) to obtain \(\lambda_{k+1}\), then horizontally back to the diagonal to start the next step. The iterates walk toward the intersection of \(g\) with the \(45^{\circ}\) line, and the shallower \(g\) is at that crossing — the smaller \(|g'|\) — the larger each stride toward it.

Code 
lam <- seq(0.2, 3, length.out = 300)

     main = TeX(r"(fixed-point iteration: the cobweb)"))

The method needs no derivatives, but the rearrangement must be found by hand, and different rearrangements of the same equation can converge at different speeds or diverge outright. Geometrically, a rearrangement with \(|g'| > 1\) at the crossing produces a cobweb that spirals outward instead of inward.

5.2.3 Bisection

If \(S\) is continuous and \(S(a)\) and \(S(b)\) have opposite signs, a root lies in \([a, b]\). Evaluate \(S\) at the midpoint and retain whichever half still changes sign.

Code 
bisection <- function(S, a, b, tol = 1e-10) {
  if (S(a) * S(b) > 0) stop("endpoints do not bracket a root")
  k <- 0
  while (b - a > tol) {
    m <- (a + b) / 2
    if (S(a) * S(m) <= 0) b <- m else a <- m
    k <- k + 1
  }
  c(root = (a + b) / 2, iter = k)
}

The schematic below draws the bracket at each iteration as a bar beneath the score curve. The dot is the midpoint, and the dotted line carries it up to the curve, where its sign decides which half survives.

     main = TeX(r"(bisection: each step halves the bracket)"))

  if (S_d(a) * S_d(m) <= 0) b <- m else a <- m
}

The bracket halves at every step, so after \(k\) iterations the error is at most \((b - a)/2^{k}\) and the iteration count is known in advance: about \(\log_2\{(b-a)/\text{tol}\}\), regardless of the shape of \(S\). Bisection cannot diverge, which makes it the natural fallback when a faster method misbehaves. R’s uniroot uses Brent’s method, which retains the bracketing guarantee while interpolating for speed.

5.2.4 Newton–Raphson

5.2.4.1 Derivation

Approximate the score by its tangent line at \(\theta_k\) and solve for where the tangent crosses zero: \[S(\theta) \approx S(\theta_k) + S'(\theta_k)(\theta - \theta_k) = 0 \implies \theta_{k+1} = \theta_k - \frac{S(\theta_k)}{S'(\theta_k)} = \theta_k - \frac{\ell'(\theta_k)}{\ell''(\theta_k)} .\]

Equivalently, replace \(\ell\) by its second-order Taylor expansion at \(\theta_k\) and jump to the maximum of that parabola. For an exactly quadratic \(\ell(\theta) = -a(\theta - u)^2 + C\) with \(a > 0\) we have \(\ell' = -2a(\theta - u)\) and \(\ell'' = -2a\), so \[\theta_{k+1} = \theta_k - \frac{-2a(\theta_k - u)}{-2a} = u\] in one step from any starting value. The normal-mean example of the previous section is exactly of this form: Newton converges immediately.

The left panel below traces three steps. At each iterate, the tangent to the score is followed down to the horizontal axis, and where it lands is the next iterate. As the curve straightens near the root, the tangent becomes an excellent approximation and the steps land almost exactly on the answer.

The right panel contrasts one Newton step with one step of the method of scoring from the same point. Newton uses the actual slope \(S'(\lambda_k)\); scoring uses \(-nI(\lambda_k)\), the slope averaged over hypothetical datasets. The two lines differ away from the root and coincide as \(\lambda_k\) approaches it.

5.2.5 Advantage: quadratic convergence

Let \(e_k = \theta_k - \hat\theta\) and expand \(S(\hat\theta) = 0\) about \(\theta_k\): \[0 = S(\theta_k) - S'(\theta_k)e_k + \tfrac12 S''(\xi)e_k^{2} \implies e_{k+1} = e_k - \frac{S(\theta_k)}{S'(\theta_k)} = \frac{S''(\xi)}{2S'(\theta_k)}\,e_k^{2} .\]

The error is squared at each step, so the number of correct digits roughly doubles. Two conditions appear in the constant: \(S'(\hat\theta) \ne 0\), meaning the maximum is a genuine peak and not a flat spot, and \(S''\) bounded near the root. Asymptotic normality says that log-likelihoods are approximately quadratic near the MLE, which is why Newton is so effective there.

Code 
newton <- function(S, dS, x0, tol = 1e-10, maxit = 100, trace = FALSE) {
  for (k in 1:maxit) {
    x1 <- x0 - S(x0) / dS(x0)
    if (trace) cat(sprintf("iter %2d: %.10f\n", k, x1))
    if (!is.finite(x1)) stop("diverged")
    if (abs(x1 - x0) < tol) return(c(root = x1, iter = k))
    x0 <- x1
  }
  stop("not converged")
}

5.2.6 Problem: divergence

Newton uses only local information, so the quadratic model can be badly wrong away from the maximum. Three failures occur:

  • wrong curvature — where \(\ell'' > 0\) the model is a bowl, and the step heads toward a minimum or off to infinity;
  • overshooting — where the score is nearly flat, \(S'(\theta_k) \approx 0\) produces an enormous step, possibly outside the parameter space;
  • multiple roots — the iteration converges to whichever stationary point it happens to reach, which need not be the global maximum.

The single-observation Cauchy likelihood is the standard illustration. With one observation at zero, \(f(\theta) = -\ell(\theta) = \log(1 + \theta^{2})\) and \(s(\theta) = f'(\theta) = 2\theta/(1 + \theta^{2})\), whose only root is \(\theta = 0\). The score rises, turns over at \(\theta = 1\), and decays to zero in the tails — exactly the flat region that defeats Newton.

Code 
lik <- function(t) log(1 + t^2)                    # negative log-likelihood

ds  <- function(t) 2 * (1 - t^2) / (1 + t^2)^2

newton_trace <- function(s, ds, x0, iters = 8) {
  path <- numeric(iters + 1); path[1] <- x0
  for (k in 1:iters) {
    x0 <- x0 - s(x0) / ds(x0)
    path[k + 1] <- if (is.finite(x0)) x0 else NA
  }
  path
}

5.2.7 Safeguards

Three remedies cover most cases. Start from a robust estimate — the sample median for a location model. Apply step halving: accept the full Newton step only if it improves the log-likelihood, otherwise halve it until it does. Or replace the observed curvature by the expected information, giving the method of scoring, \[\theta_{k+1} = \theta_k + \frac{S(\theta_k)}{n I(\theta_k)} ,\] in which the divisor is positive by construction, so every step ascends. Near the MLE \(nI(\hat\theta) \approx -\ell''(\hat\theta)\), so scoring inherits Newton’s speed while being far more stable away from the optimum. Its cost is that the expectation must be available in closed form.

Code 
safe_newton <- function(ll, S, dS, x0, lower = -Inf, upper = Inf,
                        tol = 1e-10, maxit = 100, max_halve = 40) {
  f0 <- ll(x0)
  for (k in 1:maxit) {
    step <- -S(x0) / dS(x0)
    if (dS(x0) > 0) step <- sign(S(x0))          # wrong curvature: just move uphill
    for (h in 0:max_halve) {                     # halve until feasible and improving
      x1 <- x0 + step / 2^h
      if (x1 > lower && x1 < upper && is.finite(ll(x1)) && ll(x1) >= f0) break
    }
    if (abs(x1 - x0) < tol) return(c(root = x1, iter = k, halvings = h))
    x0 <- x1; f0 <- ll(x1)
  }
  stop("not converged")
}

5.2.8 Golden Section Search

Golden section minimizes \(f = -\ell\) directly, using no derivative at all, which makes it the method of choice when \(\ell\) is not differentiable or its derivative is unreliable. Keep a bracket \([x_l, x_u]\) containing the minimum of a unimodal \(f\), with two interior points placed at the golden ratio \(g = (3 - \sqrt5)/2 \approx 0.382\) of the way in from each end. Comparing the two interior values discards one end, and the ratio is chosen precisely so that the surviving interior point is correctly positioned for the next iteration: one new evaluation per step, with the bracket shrinking by the factor \(0.618\).

Code 
golden <- function(f, brack.int, eps = 1e-4, ...) {
  g <- (3 - sqrt(5)) / 2
  xl <- min(brack.int); xu <- max(brack.int)
  tmp <- g * (xu - xl)
  xmu <- xu - tmp; xml <- xl + tmp
  fl <- f(xml, ...); fu <- f(xmu, ...)
  while (abs(xu - xl) > (1e-5 + abs(xl)) * eps) {
    if (fl < fu) {
      xu <- xmu; xmu <- xml; fu <- fl
      xml <- xl + g * (xu - xl); fl <- f(xml, ...)
    } else {
      xl <- xml; xml <- xmu; fl <- fu
      xmu <- xu - g * (xu - xl); fu <- f(xmu, ...)
    }
  }
  if (fl < fu) xml else xmu
}

5.3 Example: Poisson Data With Zeros Unobserved

5.3.1 The Model

Counts are often recorded only when positive: a study of hospital stays sees admitted patients, a survey of litters sees litters that exist. If \(Y \sim \mathrm{Poisson}(\lambda)\) and we observe \(X = Y \mid Y > 0\), \[P(x \mid \lambda) = \frac{e^{-\lambda}\lambda^{x}}{x!}\cdot\frac{1}{1 - e^{-\lambda}}, \qquad x = 1, 2, \ldots\]

Dropping the factorial terms, which do not involve \(\lambda\), \[\ell(\lambda) = \left(\sum_i x_i\right)\log\lambda - n\left[\lambda + \log\left(1 - e^{-\lambda}\right)\right],\] \[S(\lambda) = \frac{\sum_i x_i}{\lambda} - \frac{n}{1 - e^{-\lambda}}, \qquad S'(\lambda) = -\frac{\sum_i x_i}{\lambda^{2}} + \frac{n e^{-\lambda}}{\left(1 - e^{-\lambda}\right)^{2}} .\]

Since \(E(X) = \lambda/(1 - e^{-\lambda})\), taking \(-E[S'(\lambda)]\) gives the expected information \[n I(\lambda) = \frac{n}{\lambda\left(1 - e^{-\lambda}\right)} - \frac{n e^{-\lambda}}{\left(1 - e^{-\lambda}\right)^{2}} .\]

The score equation has no closed-form root, but the likelihood is unimodal — an ideal problem on which to compare all the methods against a single known answer.

5.3.2 The Three Iterations

Each method below returns the whole sequence of iterates together with the log-likelihood attained, so the trajectories can be compared directly.

Simple iteration rearranges \(S(\lambda) = 0\) as \[\frac{\bar x}{\lambda} = \frac{1}{1 - e^{-\lambda}} \iff \lambda = \bar x\left(1 - e^{-\lambda}\right) = g(\lambda),\] with contraction factor \(g'(\lambda) = \bar x e^{-\lambda}\).

Code 
nzp.simple.iteration <- function(n, r, lambda0 = mean(n)) {
  mean.n <- mean(n); lambda <- numeric(r + 1); lambda[1] <- lambda0
  for (i in 1:r) lambda[i + 1] <- mean.n * (1 - exp(-lambda[i]))
  data.frame(lambda = lambda, log.lik = nzp.log.likelihood(n, lambda))
}

nzp.newton.raphson <- function(n, r, lambda0 = mean(n)) {
  mean.n <- mean(n); lambda <- numeric(r + 1); lambda[1] <- lambda0
  for (i in 1:r) {
    e <- exp(-lambda[i])
    lambda[i + 1] <- lambda[i] -
      (mean.n / lambda[i] - 1 / (1 - e)) / (e / (1 - e)^2 - mean.n / lambda[i]^2)
  }
  data.frame(lambda = lambda, log.lik = nzp.log.likelihood(n, lambda))
}

nzp.method.of.scoring <- function(n, r, lambda0 = mean(n)) {
  mean.n <- mean(n); lambda <- numeric(r + 1); lambda[1] <- lambda0
  for (i in 1:r) {
    e <- exp(-lambda[i])
    lambda[i + 1] <- lambda[i] -
      (mean.n / lambda[i] - 1 / (1 - e)) / ((e / (1 - e) - 1 / lambda[i]) / (1 - e))
  }
  data.frame(lambda = lambda, log.lik = nzp.log.likelihood(n, lambda))
}

5.4 Postscript: Interval Data and a Flat Likelihood

Not every likelihood is well approximated by a parabola, and when it is not, the information-based standard error misleads. Suppose each Poisson observation is known only to lie in an interval \([l_i, h_i]\). Then \[\ell(\lambda) = \sum_{i=1}^{n} \log \Pr\left(l_i \le X_i \le h_i \mid \lambda\right) = \sum_{i=1}^{n} \log \sum_{x = l_i}^{h_i} \frac{e^{-\lambda}\lambda^{x}}{x!} .\]

The inner sum is computed on the log scale with the log-sum-exp trick to avoid underflow, and the maximization is delegated to nlm, which returns a numerical Hessian and hence a standard error.

Code 
log_sum_exp <- function(lx) { mlx <- max(lx); mlx + log(sum(exp(lx - mlx))) }

poisson_log_likelihood <- function(lambda, low, high)
  sum(vapply(seq_along(low),
             function(i) log_sum_exp(dpois(low[i]:high[i], lambda, log = TRUE)),
             numeric(1)))
### equivalently, and faster: sum(log(ppois(high, lambda) - ppois(low - 1, lambda)))

poisson_mle <- function(low, high) {
  if (length(low) != length(high)) stop("low and high have different lengths")
  if (any(floor(low) != low) || any(floor(high) != high)) stop("interval ends are not integers")

  fit <- nlm(function(l) -poisson_log_likelihood(l, low, high),
             p = (mean(low) + mean(high)) / 2, hessian = TRUE)
  est <- fit$estimate; sd <- sqrt(1 / fit$hessian[1, 1])
  list(est = est, sd = sd, CI = est + c(-1.96, 1.96) * sd)
}

       xlab = TeX(r"($\lambda$)"), ylab = TeX(r"($\ell(\lambda) - \ell(\hat{\lambda})$)"),
       main = TeX(sprintf(r"(%s)", iv$lab)))
  abline(h = -1.92, col = 4, lty = 3)
}

With narrow intervals the log-likelihood is sharply peaked and the standard error is small and reliable. With wide intervals, most of which include the lower boundary at zero, the log-likelihood is nearly flat over a broad range: the curvature at the maximum is tiny, the reported standard error is large, and — because the curve is visibly asymmetric and non-quadratic — even that large value understates the true uncertainty. The information-based standard error is an asymptotic approximation resting on local quadratic behaviour, and this is what its failure looks like. When the log-likelihood is this shape, report a likelihood-based interval, read off where \(\ell\) drops by 1.92, instead of a Wald interval.
